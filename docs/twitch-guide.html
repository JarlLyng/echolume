Echolume Twitch Guide

Interactive Twitch Streaming

Turn your live stream into an interactive audiovisual experience. By connecting Echolume to your Twitch chat feed, viewers can trigger effects and control rendering parameters in real time.

How it works

Echolume uses a native WebSocket client to connect directly to public Twitch IRC chat streams (wss://irc-ws.chat.twitch.tv:443). The connection is completely anonymous and read-only (registering as a guest justinfan* account). Echolume never requires your password, streaming keys, or Twitch OAuth logins, making the integration highly secure.

Setup guide

  1. Launch Echolume on your Mac.
  2. In the right-hand Visuals & Integrations panel, locate the Twitch Chat section.
  3. Toggle Twitch Chat to enabled.
  4. Enter your Twitch username in the Channel Name field (do not include the # symbol or URLs).
  5. Echolume connects automatically. A status pill changes colors to indicate connectivity (green for connected, yellow for retrying, red for failed, gray for disabled).
  6. Click Ready to enter fullscreen live visual rendering.

Twitch chat commands reference

Your viewers can type the following commands in your channel chat to drive visuals. Commands are rate-limited to 1 command per second globally to prevent chat spam from thrashing visuals.

Command Description / Supported Values Usage Example
!theme [name] Switch visual color palette and trails (summer, winter, dark ambient, techno club, neon lines, monochrome, sunset, nebula, vapor, acid) !theme dark ambient
!scene [name] Switch rendering geometry (radial, flow, grid, spiral, tunnel, kaleidoscope, plasma, spectrumring, ridgeline, wireframeburst) !scene kaleidoscope
!shape [name] Switch procedural shapes (blobs, circles, lines, grid, particles) !shape lines
!randomize Trigger a random combination of themes, shapes, and rendering seeds !randomize
!glitch Trigger a short visual glitch feedback warp overlay !glitch
!abstract [0-100] Set the visual complexity knob (scales lines, shapes, and spacing variables) !abstract 75
!preset [name] Recall a user-saved visual preset configuration by its unique name !preset techno-pulse

Streaming workflow with OBS Studio

Two displays help. Echolume renders on your Mac's graphics card while OBS encodes the stream. Running Echolume fullscreen on a second display keeps your OBS controls free and gives the visuals the whole screen.

To broadcast interactive visuals to your stream:

  1. Follow the OBS Studio Setup Guide to send the music from OBS into Echolume through BlackHole.
  2. Add a macOS Screen Capture source in OBS to show Echolume, set to Window Capture or Display Capture as the OBS guide describes.
  3. Set the Echolume source depth below your camera overlay or stream widgets.
  4. Go live! Viewers can immediately type commands in chat, which will manipulate the background visuals in real time.

Twitch Troubleshooting

Echolume fails to connect to chat (status indicator stays red)
Verify that your Mac has active internet access. Check that your Twitch channel name is spelled correctly (it should match your Twitch username exactly, e.g., twitch_streamer). Ensure local firewall policies do not block outgoing secure WebSocket connections on port 443.
Commands do not update the visuals
Confirm that Twitch Chat is enabled in Setup and that its status indicator shows a connection. Commands work in Setup as well as in Live. A theme, scene or shape name that does not match exactly is ignored, so check the spelling against the command list in this guide. Theme names can contain spaces, for example dark ambient.
Commands lag or viewer changes are ignored
To protect graphics performance, Echolume applies a strict global cooldown of 1 second between commands. If multiple viewers type commands simultaneously, excess commands are discarded. Viewer changes apply on top of active music analysis.
